# Categories and tags

Turn on the **Advanced options** (the sliders button in the Quick Note title bar) to see two boxes under the text:

- **Category** sends the note to its own file instead of the Quick Note file.
- **Tag** adds any number of tags. They are written as one line, such as `**Tags:** #work #urgent`, under the heading.

A category or tag can have a **keyword**: a note that contains it is filed or tagged by itself. Manage them in the **Tags & Categories** panel.
