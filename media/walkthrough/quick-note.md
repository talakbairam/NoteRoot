# Try Quick Note

The **Quick Note** box under the tree adds a note to a single file, without interrupting what you are doing.

- Type or paste text and press **Save**.
- The note is added at the end of `quick-notes.md` with a time stamp heading. The file is not opened.
- Select text in any editor and run **NoteRoot: Add Selection to Quick Note** to collect it in the same file.
- Bind your own keyboard shortcut to **NoteRoot: Focus Quick Note** to jump into the box from anywhere.
