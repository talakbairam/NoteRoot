# Sync with GitHub

Click the GitHub row at the top of the Notes tree, or open the **Sync** page from the `...` menu of Notes, and connect your notes folder to a GitHub repository. No git and no other app are needed.

- **Push** sends your changes, **Pull** brings the ones made on another computer, **Refresh** compares. Nothing is sent until you press a button.
- A file changed on both sides asks what to keep, and nothing is overwritten silently.
- A new repository can be **encrypted** with a master key before the first push. The master key is never stored, and **it cannot be recovered**.
