# Choose your notes folder

NoteRoot keeps your notes as plain files in one folder that you choose.

- Pick an existing folder or create a new one in the dialog.
- The folder can live anywhere, for example in a cloud-synced directory.
- NoteRoot adds a small hidden `.noteroot` folder with a technical config file. Your notes are never changed.

You can switch to another folder at any time with **NoteRoot: Change Notes Folder**.
