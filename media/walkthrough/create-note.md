# Create your first note

Use the **New File** button above the notes tree.

- A name without an extension, such as `ideas`, becomes `ideas.md`. A name like `todo.txt` is kept as it is.
- Folders work like in the Explorer: create, rename, delete and drag items to move them.
- Single click opens a preview tab. Double click opens a permanent tab.
- Deleting moves items to the Trash, after you confirm.
